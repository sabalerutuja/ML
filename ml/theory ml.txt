# Practical 1: Uber Fare Prediction Using Regression

### 1. Aim

To predict Uber ride fare using Linear Regression, Ridge Regression and Lasso Regression algorithms.

### 2. Objectives

1. To load and understand the Uber dataset.
2. To clean the data by handling missing values and outliers.
3. To calculate ride distance using the Haversine formula.
4. To train regression models and predict fare amounts.
5. To compare model performance using R² score and RMSE.

### 3. Theory

Regression is a supervised machine learning technique used to predict continuous numerical values.

In this practical, the Uber dataset is used to predict ride fare based on trip details such as distance, passenger count and pickup time.

Three algorithms are used:

* **Linear Regression:** Predicts fare by finding the relationship between input features and fare amount.
* **Ridge Regression:** Uses L2 regularization to reduce overfitting.
* **Lasso Regression:** Uses L1 regularization and can reduce less important feature coefficients to zero.

The dataset is cleaned, processed and divided into training and testing data. The models are trained and evaluated using R² score and RMSE.

### 4. Algorithm / Procedure

1. Import the required Python libraries.
2. Load the Uber dataset.
3. Display and understand the dataset.
4. Remove missing values.
5. Convert pickup date and time into date-time format.
6. Extract hour, day and month.
7. Calculate distance using the Haversine formula.
8. Remove unnecessary columns and invalid values.
9. Detect and remove outliers using Z-score.
10. Divide the dataset into input features and target variable.
11. Split the data into training and testing sets.
12. Apply Linear Regression, Ridge Regression and Lasso Regression.
13. Predict fare amounts.
14. Evaluate models using R² score and RMSE.

### 5. Result

Uber fare prediction was successfully performed using three regression algorithms.

| Algorithm         | R² Score |   RMSE |
| ----------------- | -------: | -----: |
| Linear Regression |   0.7626 | 3.0385 |
| Ridge Regression  |   0.7626 | 3.0385 |
| Lasso Regression  |   0.7623 | 3.0404 |

### 6. Conclusion

Thus, Uber fare prediction was successfully implemented using Linear Regression, Ridge Regression and Lasso Regression. Linear Regression and Ridge Regression gave the same best R² score.

In this practical, the email dataset contains word-frequency features. The target variable represents spam or non-spam emails.

Two algorithms are used:

* **SVM:** Support Vector Machine is a supervised learning algorithm that separates data into different classes.
* **KNN:** K-Nearest Neighbors classifies data based on the nearest data points.

# Practical 3: Customer Churn Prediction Using ANN

### 1. Aim

To predict customer churn using an Artificial Neural Network (ANN).

### 2. Objectives

2. To preprocess and encode categorical data.
3. To divide the dataset into training and testing sets.
4. To build an Artificial Neural Network model.
5. To predict whether a customer will leave the bank or not.
6. To evaluate the model accuracy.

### 3. Theory

Customer churn means when a customer stops using a company's products or services.

Artificial Neural Network (ANN) is a deep learning technique inspired by the working of the human brain. It consists of interconnected neurons arranged in layers.

In this practical, ANN is used to predict whether a bank customer will leave the bank or continue using its services.

The dataset is preprocessed using encoding and feature scaling. A neural network is created using Dense and Dropout layers. The model is trained using the Adam optimizer and binary cross-entropy loss function.

### 4. Algorithm / Procedure

1. Import the required Python libraries.
2. Install and import TensorFlow and Keras.
3. Load the customer churn dataset.
4. Separate input features and target variable.
5. Encode categorical variables such as Gender and Geography.
6. Split the dataset into training and testing sets.
7. Apply StandardScaler for feature scaling.
8. Create a Sequential ANN model.
9. Add Dense layers with ReLU activation.
10. Add a Dropout layer to reduce overfitting.
11. Add an output layer with Sigmoid activation.
12. Compile the model using Adam optimizer and binary cross-entropy.
13. Train the model for 20 epochs.
14. Predict customer churn.
15. Calculate the final accuracy.

### 5. Result

Customer churn prediction was successfully performed using an Artificial Neural Network.

**Final Accuracy: 84.25%**

### 6. Conclusion

Thus, customer churn prediction was successfully implemented using an Artificial Neural Network. The model achieved 84.25% accuracy.

# Practical 4: Diabetes Prediction Using KNN

To predict diabetes using the K-Nearest Neighbors (KNN) classification algorithm.

4. To apply the KNN classification algorithm.
5. To predict diabetes outcomes.
6. To evaluate the model using performance metrics.

### 3. Theory

Diabetes prediction is a classification problem in machine learning. It is used to predict whether a person belongs to the diabetic or non-diabetic category based on medical information.

K-Nearest Neighbors (KNN) is a supervised machine learning algorithm. It classifies a new data point based on the majority class of its nearest neighbours.

In this practical, the diabetes dataset contains features such as Glucose, Blood Pressure, BMI, Age and Insulin.

Missing or invalid zero values are replaced with mean values. The dataset is divided into training and testing sets. The KNN algorithm is applied to predict the outcome.

### 4. Algorithm / Procedure

1. Import the required Python libraries.
2. Load the diabetes dataset.
3. Display the first five records.
4. Check for missing values.
5. Replace invalid zero values with NaN.
6. Fill missing values using the column mean.
7. Separate input features and target variable.
8. Split the dataset into training and testing sets.
9. Detect outliers using boxplots and IQR.
10. Create the KNN classifier with K = 5.
11. Train the model using training data.
12. Predict the diabetes outcome.
13. Calculate confusion matrix, accuracy, precision, recall and F1-score.
14. Compare different K values such as 3, 5 and 7.

### 5. Result

Diabetes prediction was successfully performed using the KNN algorithm.

| K Value | Accuracy |
| ------- | -------: |

# Practical 5: Sales Data Clustering Using K-Means

### 1. Aim

To perform clustering on sales data using the K-Means clustering algorithm.

### 2. Objectives

1. To load and understand the sales dataset.
2. To preprocess the numerical data.
3. To detect and handle outliers using IQR.
4. To normalize the data using StandardScaler.
5. To apply K-Means clustering.
6. To find a suitable number of clusters using the Elbow Method and Silhouette Score.
7. To visualize the clusters.

### 3. Theory

Clustering is an unsupervised machine learning technique used to group similar data points together.

K-Means is a clustering algorithm that divides a dataset into a specified number of clusters. Each cluster has a centre called a centroid.

In this practical, the sales dataset is used to group similar sales records. The data is cleaned, numerical features are selected and outliers are handled using IQR.

StandardScaler is used to normalize the data. The Elbow Method and Silhouette Score are used to evaluate the number of clusters. Finally, clusters are visualized using a scatterplot.

### 4. Algorithm / Procedure

1. Import the required Python libraries.
2. Load the sales dataset.
3. Display and understand the dataset.
4. Remove unnecessary columns.
5. Check for missing values.
6. Select numerical columns.
7. Detect outliers using boxplots and IQR.
8. Handle outliers using IQR capping.
9. Normalize the data using StandardScaler.
10. Apply the Elbow Method for K values from 1 to 10.
11. Calculate the inertia for each K value.
12. Calculate Silhouette Scores for different K values.
13. Apply K-Means clustering with K = 3 for visualization.
14. Display the clusters using a scatterplot.

### 5. Result

Sales data clustering was successfully performed using the K-Means algorithm.

The highest Silhouette Score among the tested values was:

**K = 2, Silhouette Score = 0.2154**

The practical also visualized the data using **K = 3 clusters**.

### 6. Conclusion

Thus, sales data clustering was successfully implemented using the K-Means algorithm. The Elbow Method and Silhouette Score were used to evaluate the clusters, and the results were visualized using a scatterplot.
